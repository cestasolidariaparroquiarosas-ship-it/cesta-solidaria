# Cesta solidaria

Aplicación para gestionar la cesta solidaria parroquial. Sirve para gestionar colaboradores y el catálogo de alimentos, preparar las cestas semanales, repartir el gasto de forma equilibrada entre colaboradores y recoger las confirmaciones por correo.

- **Qué hace y por qué:** `docs/sdlc/` (intent, spec y plan de cada iteración).
- **Cómo se trabaja en el código:** `CLAUDE.md`.
- **Puesta en marcha, cómo volver a una versión anterior y copias de seguridad:** `docs/operacion.md`.
- **Cambios por versión:** `CHANGELOG.md`.
